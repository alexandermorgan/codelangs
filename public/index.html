GitHub token (optional, raises the rate limit)

Reading someone's history takes one GitHub API request per commit. Without a token, GitHub allows only 60 requests an hour from your network, so a token is close to essential. Progress is saved in your browser, and if a limit stops a load, the chart shows an even sample of the commits read so far and the next try carries on where it stopped.

A token raises the limit to 5,000 requests an hour, and lets the chart include private repositories the token can read. Create a fine-grained token:

  • Public repositories only: choose “Public repositories” and add no permissions.
  • Including private repositories: choose “All repositories” (or pick some) and give it read-only access to Contents, which lets it read commits and their diffs. Metadata (read-only) is added automatically. A fine-grained token covers one account or organization, so organizations' private repositories need a token whose resource owner is that organization.

The token is kept in this browser's local storage and sent only to api.github.com. Results, including those from private repositories, are cached in this browser only.

How it works

Everything runs in your browser against GitHub's API. The tool finds the repositories someone commits to: their own (not forks), ones they are a member of, private ones your token can read, ones where their pull requests were merged, and ones where GitHub's commit search finds their commits. In each, it lists their commits on the default branch, so only accepted commits count. Merge commits are skipped, and a commit that appears in several repositories counts once.

For each commit it reads the list of changed files and gives each file's added and deleted lines to the language of its extension: .py is Python, .ts is TypeScript, Makefile is Makefile, and so on. Files that aren't code aren't counted: data and config formats (JSON, YAML, TOML, XML), prose (Markdown, text), lockfiles, binaries, and generated or vendored code such as minified bundles or anything under node_modules/, vendor/ or dist/. Commits are dated by when they were written. If someone has used more than eight languages, the seven with the most lines changed get their own colors and the rest are combined as “Other”. Each language keeps its color whatever time span is shown.

Without a token only public repositories count, and only commits GitHub can link to the account through their email address. Up to 5,000 commits per repository are read.
